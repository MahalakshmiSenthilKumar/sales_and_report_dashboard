# Sales and Report Dashboard

## 📊 Project Overview

**Sales and Report Dashboard** is an Excel-based data analysis project created to analyze sales performance and customer-related insights.

The dashboard uses Excel Pivot Tables and charts to present sales and order information in an easy-to-understand visual format.

## 🎯 Objectives

- Analyze monthly sales performance
- Compare order volume and sales amount
- Compare sales distribution between men and women
- Create an interactive and easy-to-read dashboard
- Practice Excel data analysis and reporting skills

## 🛠️ Tools & Technologies

- Microsoft Excel / WPS Office
- Pivot Tables
- Pivot Charts
- Data Analysis
- Dashboard Design

## 📁 Workbook Structure

The workbook contains the following sheets:

- **project dataset** – Source sales/customer dataset
- **compare sales and order** – Comparison of sales and order information
- **men vs women** – Gender-based analysis
- **Dashboard** – Final visual dashboard
- **Sheet1 / Sheet2** – Supporting worksheets

## 📈 Dashboard Features

The dashboard includes:

### 1. Monthly Sales & Order Analysis
A column chart is used to compare monthly:

- Order ID values
- Sales/Amount values

The report covers months such as January, February, March, April, and December based on the available dataset.

### 2. Men vs Women Analysis
A pie chart shows the percentage distribution between:

- Men
- Women

This helps visualize customer/order distribution by gender.

## 🔍 Key Skills Demonstrated

- Data cleaning and organization
- Pivot Table creation
- Data aggregation
- Monthly sales analysis
- Gender-based analysis
- Chart creation
- Dashboard design
- Excel reporting

## 🚀 How to Use

1. Download the Excel workbook from this repository.
2. Open it using Microsoft Excel or WPS Office.
3. Open the **Dashboard** sheet.
4. Review the charts and analysis.
5. Use the source dataset and Pivot Tables to explore the underlying data.
